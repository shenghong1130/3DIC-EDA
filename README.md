# 3DIC EDA

3DIC 全局布线赛题的代码、评估工具和公开测试资料。

## 目录

- `EDA/submission_example/submission_example/`：示例布线程序（C++、Python）及编译、运行脚本。
- `EDA/eda-elite-challenge2026-2026.9.15/eda-elite-challenge2026/`：评估代码、依赖库、Dockerfile 和示例数据。
- `EDA/评估程序/`：评分程序和说明。
- `EDA/公开测试用例1011/`：公开测试用例。
- `EDA/赛题八公开数据集/`：公开数据集和环境配置。
- `EDA/赛题解答-1.docx`、`EDA/赛题解答-2.docx`：赛题解答资料。
- `2DIC 3DIC compare.png`：对比图片。

编译、运行方式和评测要求请参阅各子目录中的 README。

本机 TigerVNC 文件、连接配置、日志、缓存和临时文件不纳入版本控制。
