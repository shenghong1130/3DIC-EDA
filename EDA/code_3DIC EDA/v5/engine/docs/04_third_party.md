# 第三方组件与材料说明

运行依赖只有系统 Python 3.10 标准库和 bash，不需要外部 EDA 工具、LLM 服务、第三方 Python 包、FLUTE 查找表或评分器二进制。报告制作工具不是运行依赖。

提交包不包含官方输入、公开 GUIDE、外部电路数据、其他参赛队评估器或隐藏测试资料。开发回归集保留在本地工作目录，不参与评测运行。baseline_v12/ 是本工程基线源码的冻结副本。

参考资料：官方 Q&A，https://docs.qq.com/doc/DQlZueVFKeXhTbkVZ；Open3DBench，https://arxiv.org/abs/2503.12946；ISPD routing contest，https://www.ispd.cc/contests/19/tutorial.htm。文献用于研究参考，程序不在线调用这些服务。
