# 算法原理与通用性

以 GCell 和金属层构建三维离散图，使用稀疏 MST、有限 Hanan 候选和有界 A* 生长共享树。搜索可接入已有连通树的任意位置，并将实际 PIN 的可用 RECT/PORT 作为终点集合，避免重复的绕线和接入层堆叠。

拥塞估计采用溢出/容量平方和，并在固定占用与可移动导线共享时留一条轨道余量。模型是输入派生的保守估计，不声称精确复现官方计费；TSV 在大 GCell 中的满格资源上界可能牺牲部分优化空间。对零容量使用高代价。

抬层允许的线长增长由拥塞严重程度统一决定，范围 1%-8%，同时要求模型拥塞下降及组合目标改善。TSV 移位连接所有同 Die 分量并裁剪旧尾部。PIN 逃逸保持 TSV 几何，限制线长增长 0.5%。共享树缩线只接受严格降低线长且逐格风险不增加的候选。

共享树搜索预算为 min(8000, max(2048, ceil(网络数×0.04)))，并采用每条路径的展开上限；其余预算也为全局统一参数。不存在公开案例/网络名称参数表，热增益按统一输入统计估计，不写死官方各案例 G 值。

规则依据为赛题正式指南、2026-11-03 评分更新、2026-11-06 20:22 的官方 Q&A 快照。M10/M11 含 PIN/OBS 的落点禁止 TSV，包括自身 PIN；采用实际 PIN 形状的正面积接入和 DIE 末端网格截断。未回答的问题不作为新增约束。
