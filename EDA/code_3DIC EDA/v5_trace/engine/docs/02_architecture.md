# 设计架构

run.sh 调用 final_router.py。baseline_v12/ 为固定版本的独立基线，从输入生成初始三维布线。随后依次执行：TSV 落点冲突修复、拥塞抬层、受保护缩线、TSV 移位与树重接、PIN 接入逃逸、共享树迷宫缩线、网格图裁剪。

design.py 处理 LEF/DEF、MACRO ORIGIN、八类方向变换、实际 PIN RECT/PORT、OBS、轨道及非均匀网格。资源与热偏好模型仅依赖本次输入及已生成路径。运行入口不读取验证记录、公开案例名称、保存的 GUIDE 或官方评分报告。

各阶段独立进程运行，以完整几何检查作为交接门槛。最终检查网络集合、实际 PIN 覆盖、层与方向、DIE 边界、GCell 对齐、同 Die 路径、相邻层连通、TSV 唯一性及接口 PIN/OBS 禁放。源文件保持原样并复核哈希。

本地检查用于提前发现问题，不能替代官方合法性判定或详细布线 DRC。隐藏用例的质量由最终评测确定。
