## 实际输入格式

- DEF：5.8、`UNITS DISTANCE MICRONS 2000`；有 COMPONENTS、PINS、NETS、TRACKS、GCELLGRID；实例实际含 N、FS 方向。toy 无顶层 PINS，sample001 有 12 个。
- LEF：Routing/CUT 层、VIA 和 VIARULE、Macro SIZE/ORIGIN/PIN/PORT/OBS；所核查的三个设计使用 RECT 几何。
- 热 JSON：`meta.ambientTemp` 和 `nodes` 数组；节点为 `[x_um_local,y_um_local,z,temperature]`。不同 z 可能共享 XY，本地先对同一 XY 求均值，再落到 GCell。
- Guide：独立网络名、圆括号、整数 DBU 矩形和 LEF 原始层名。参考 Guide 仅供解析、展示和比较。

## 规则冲突及处理

| 项目 | 旧代码 / 较早说明 | 较新 DOCX / Q&A | 本版处理 |
|---|---|---|---|
| 实例引脚方向 | 旧 checker 直接平移，未应用方向 | 物理引脚需按布局方向变换 | 实现八方向；若工具覆盖口径不一致，记录实际失败，不能篡改检查器 |
| 跨 Die | 相邻层 + 特例 M10/M11 | Die 内 Net 禁止借用另一 Die；跨 Die 唯一可判定 TSV | Die 内严格限制层范围；跨 Die 两侧分开建树，使用一个 TSV |
| 首选方向 | 旧 checker 主要检查矩形 XY 接触 | Q43–Q46 禁止非首选方向跨格及角接触 | 图中只允许首选方向平面边，拐弯需普通 Via |
| TSV 数量 | 旧脚本按 M10/M11 矩形重叠候选累计 | 至少一块正面积候选，不超过两块且唯一可判定 | 主动生成唯一共同 GCell；多固定候选时报错 |
| 线长 | 矩形连通图 MST + Guide 中心 HPWL proxy | GCell 覆盖 + Via/TSV，FLUTE 三维基准 | 正式值读取最新 ELF；另列图边几何长度 |
| 线长得分 | 旧脚本低于基准满分 | DOCX 写对称 `min(L,1/L)`；后续 Q53 又说明低于参考满分 | 不自行更改评分；记录二进制实际输出，对最终平台公式标记待确认 |
| 拥塞 | 旧脚本无完整 Pin/OBS 固定需求，轨道方向实现与物理方向存在差异 | 逐格逐层含 Pin/OBS、同 Net Guide 去重、TSV 附加需求 | 本地按水平 Y tracks、垂直 X tracks，加入近似固定需求；官方值单列 |
| 热网格缺失 | 旧 Python 有空格时直接异常 | DOCX 允许前行/前列有效值填充；Q&A 未明示索引细节 | 本地确定性前列/前行及反向补齐，明确不保证与二进制逐位相同 |
| 热得分 | 旧脚本 `(r+1)/2` | DOCX `0.5+0.5 tanh(G_case r)` | 不编造 G_case；正式分数取工具报告 |
| 边界 | 旧代码完全包含于 DIEAREA | DOCX 写只需交集 | 本版使用更严格的完全包含，避免借此扩大 Guide |
| 最终总分 | 单用例 45/30/25 | S1×(S2+S3)×S4；公开/隐藏名次折算 | 不把本地单用例质量分称为最终比赛总分 |
