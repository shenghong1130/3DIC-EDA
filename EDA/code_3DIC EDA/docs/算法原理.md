# 算法原理

## 输入与图

LEF 微米坐标乘 DEF DBU 后，通过 Macro 原点、实例平移和八种方向变换获得引脚中心。顶层 IO Pin 使用 PORT RECT 与 placement。
GCELLGRID 取各条语句展开线并集，加入 DIEAREA 边界、裁掉边界外网格。区间按左闭右开定位，最外边界归最后一格。
平面边仅沿该层首选方向；普通层间边必须由 LEF 的 VIA 或 VIARULE 证明可达。

## 初始布线

Die 内 Net 严格限制在对应的十层中。多 Pin 使用确定性 Prim MST，各树边执行 A* 后合并节点与边。
跨 Die Net 选择一个 TSV GCell，两侧各加入一个锚点并独立建树，最后插入 M10/M11 边。
跨 Die Net 在 M10/M11 只保留接入格、不沿界面层平面延伸，避免把界面长条的多个交叠误计为多个 TSV。

$$
c(e)=w_w\frac{\ell(e)}{p}+w_v I_{via}(e)+w_c\left[\frac{\max(0,D+1-C)}{\max(1,C)}\right]^2+w_h H.
$$

`p` 为初始 GCell 尺度，`D` 含当前路由用量和近似固定需求。TSV 位置另用几何、界面拥塞和冷区惩罚选取。
A* 启发函数为中心点曼哈顿距离成本加必需层差的 Via 成本。所有附加项非负，对当前图权重为下界。
搜索先局限包围盒加 margin，不可达时扩大；因此求得的是当前搜索范围内的最短路径，不声称全局布线总成本最优。

## 拥塞与热

每 Net 每格每层计一份使用量，TSV 在 M10/M11 各追加一份。水平层数 Y 方向的 tracks，垂直层数 X 方向的 tracks。
Pin/OBS 矩形对实际占用轨道求近似固定需求，可能存在几何重复累计，与官方逐项计费不保证一致。

$$O=\sum_v\max(0,U_v+F_v-C_v).$$

每轮给拥塞资源增加历史代价，只拆相关 Net；整轮 Overflow 未降低则回滚，保留最好结果。配置限制迭代次数、停滞轮数、搜索扩展量和时间。
TSV 候选在端子包围盒内采样，加上全部端子格；高温惩罚更低，鼓励正热相关，但不增加断路或非法跨层边。
本地 Pearson 对温升与 TSV 密度求相关；无 TSV 或方差为零显示 N/A，不虚构热分数。

## Guide

每个已访问节点对应一个真实 GCell 矩形。同层沿首选方向连续格合并；跨 Die Net 的界面格保持单格。
内部检查所有引脚节点可达、边类型合法、Guide 不越界及 TSV 唯一，然后写出整数 DBU 与原始 LEF 层名。
