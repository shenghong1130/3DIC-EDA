## 验证说明

- 官方工具本身标识 Guide / MST proxy 与 mock-DRT；PASS 不代表详细布线 DRC 或隐藏用例通过。
- 新版 sample001 热输入标为 synthetic，按官方输入原样计算；没有伪造热分数。
- 无官方报告时显示 Not Tested / NOT_EVALUATED，失败时保留原始日志。
- toy 与 sample001 的初期失败为 DEF END DESIGN/空 VIAS 段落处理，公开 case001 初期失败为 LEF PROPERTYDEFINITIONS 误识别；修复后使用新标签重跑。
- 大型 case003/case005：Not Tested。
