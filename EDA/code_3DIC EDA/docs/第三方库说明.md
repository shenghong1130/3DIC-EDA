# 第三方库说明

自主 Router 只依赖 C++17 标准库。JSON 值、严格 JSON 解析器和序列化器位于 `include/json.hpp`，由本工程实现，未引入外部代码。
辅助工具与 UI 只依赖 Python 3.10 以上标准库。浏览器端使用原生 HTML/CSS/JavaScript Canvas，无 CDN、第三方包或字体下载。

官方评分器及其 FLUTE 数据、Linux `.so`、`libfmt.so.10` 属赛题方原始资料；没有修改，也没有打进自主 Router 的 ZIP。
现有 Windows MinGW 和 Ubuntu 22.04 WSL/g++ 11.4 为本机工具链，不属于提交程序运行依赖。

本工程不重新分发官方 DEF/LEF/热图/Guide。LEF 内第三方工艺与库版权提示仍随官方原始资料保留。
